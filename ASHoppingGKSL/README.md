# ASHoppingGKSL

This directory contains the code used for the numerical calculations in the paper *Asymmetric-hopping effective theory of current-carrying bulk steady states and their effective temperature*.

## Reproducing the results

To run the parameter sweep and generate the corresponding figures, run the following command from the repository root (the directory containing `ASHoppingGKSL`):

```bash
bash ASHoppingGKSL/script/reproduce.sh
```
